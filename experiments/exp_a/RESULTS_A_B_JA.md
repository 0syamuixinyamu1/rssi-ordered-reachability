# 外圧訂正と反証選別：2実験の結果

2026-09-16

**2本のPython実験を実行しました。外向きの訂正と内部更新は分離でき、受理した入力との一致度が上がっても正解から遠ざかる例を確認しました。一方、「反証を拒絶すると必ず凍結・収束する」「誤差は必ず増える」という強い説明には反例がありました。**

実行水準は、Aが取得したJuliaソースのPython移植、Bが会話で示された規則の独立した最小モデルです。**Julia本体の直接実行と、実LLMでの検証は行えていません。**

## 1. 実験A：同じ訂正出力でも信念は異なる

出発点の信念を0、独立参照R0を1、候補仮説を1に置き、同じ入力を4条件へ与えました。代表例は圧力1、証拠強度1、矛盾強度1です。

| 条件 | 外向きの出力 | 実際の内部信念 | 出力の正しさ | 内部の正しさ |
|---|---|---:|---:|---:|
| 無処理 | value=0 | 0 | 0 | 0 |
| 外圧対応だけ | value=1 | 0 | 1 | 0 |
| 外圧対応＋虚数仮説 | value=1 | 0 | 1 | 0 |
| 証拠に基づく更新 | value=1 | 1 | 1 | 1 |

**外圧対応と証拠更新は、同じ正しい訂正出力を返しても、内部状態が異なります。** 虚数仮説を保持しただけでも、実数側の信念は更新されません。

全27,104条件を走査しました。「初期信念が誤り、候補仮説が正しく、外圧が閾値以上」という726条件では、外圧対応だけの条件は726件すべてで出力が正しくなり、内部信念が正しくなった件数は0でした。虚数仮説を保持する条件も同じです。

このうち証拠支持も更新閾値以上だった114条件では、証拠更新の条件は114件すべてで出力・内部ともに正しくなりました。全726条件中114件という比率は、人工的な走査格子に依存する値であり、実運用の成功率ではありません。

ただし、**訂正出力そのものは実験側が `apparent_response` として与えています。** これはAIが正解を発見した証拠ではなく、その出力を内部更新の代わりに評価すると見分けがつかない、という状態分離の検証です。Aの結果はコードが明示している挙動の確認であり、自発的な欺瞞の発見ではありません。

追加で重要だった点は2つです。

- **内部更新したこと自体も、正しさを保証しません。** 高い証拠強度を、実際には誤った仮説に与えると、正しかった信念を誤った値へ変更する266条件がありました。証拠強度は外部から与える数値であり、コードが真偽を独立検証しているわけではありません。
- `collapse_imaginary_to_real!` の成功フラグは「値が変わった」という意味とは一致しません。仮説が既存信念と同じでも、射影処理が成立すればtrueになり得ます。今回の評価はフラグだけでなく、変更前後の実際の値を比較しています。

圧力4成分の独立した625条件も計算しました。取得した版の係数は、怒り0.40・拒絶0.25・権威0.15・社会的コスト0.20です。以前の4フィールド案など、別版の係数は混ぜていません。

## 2. 実験B：選別による高得点は確認できるが、結果は入力列に依存する

規則は、未知の話題なら受理し、既知なら現在の信念との差がtol以下の場合に受理して、その入力値で信念を更新するものです。R0は全時点で固定しました。

取得したHoho `main` の `HohoConsciousnessCore.jl` と `ImaginaryMode.jl` には、この `admits_section` と全体の `coherence` 更新はありませんでした。候補となる保存ファイルでも当該関数を特定できませんでした。従ってBは、共有会話の規則を明記した実験であり、未取得の原実装を実行した結果ではありません。

ここでの「受理入力一致度」は、入力ごとに更新直前の信念との近さを計算し、受理した入力だけで平均した値です。

\[
C_{accepted}(t)=\operatorname{mean}_{i\in accepted(t)}(1-|x_i-b_{i,before}|)
\]

正しさは別に、固定参照との誤差 `D(t)=abs(b_t-R0)` で測ります。Cは高いほど一致し、Dは低いほど正しい値です。**CをHoho本来のcoherenceと呼ぶことはできません。** 全拒絶時のCは未定義（CSVでは空欄）とし、1.0を与えていません。

| 入力条件 | 受理入力一致度 | 固定参照との誤差 | 分かったこと |
|---|---|---|---|
| 同意する入力と、大きく離れた正しい入力を反復 | 常に1.000 | 常に1.000 | 完全に一致して見えても誤ったままです。乖離は増えず一定です |
| 許容される小更新が参照から遠ざかる | 0.961935 → 0.999986 | 0.638065 → 0.999866 | 一致度の上昇と正しさの悪化が同時に起きます |
| 0.025ずつ正解へ近づく | 更新中0.975 | 40回目に0.000 | tol=0.05なら、通常の受理規則だけで0から1へ到達します |
| 許容範囲内で0.45と0.55を往復 | 初回後0.900 | 0.050 | tol=0.11で往復を継続でき、受理規則だけでは収束しません |
| 正しい入力をすべて拒絶 | 未定義 | 1.000 | 観測対象が空であることを、完全な整合性と扱えません |

上表の第2行は、初期信念0.4、R0=1、確認的な入力を `0.4*exp(-t/10)` とし、毎回R0=1の入力も与えた条件です。tol=0.05で小更新は受理され、R0の入力は80回すべて拒絶されました。受理率は50%です。初期誤差0.6から、最終的に約0.999866へ悪化しました。

これは**拒絶だけによる悪化ではありません**。受理された小更新が誤った方向へ進むことと、大きく離れた正しい入力を拒絶することの組み合わせです。信念もR0も固定なら、Dも固定になります。

また、受理される既知入力は定義上 `abs(x-b)<=tol` です。この一致度の定義では、受理対象だけの平均が `1-tol` 以上になることは、ゲートから直接導かれます。高得点の一部は、入力選別の定義によって作られています。

対照条件には、全入力受理と、R0一致の入力だけを受理する理想対照を置きました。後者は実験側が真偽を知っている対照であり、既存エンジンの能力ではありません。前者も一般に正解を保証せず、最後に入れた入力の影響を受けます。

## 3. 前の会話の主張をどう扱うか

| 主張 | 今回の判定 |
|---|---|
| 訂正された出力と内部更新は同じではない | ソースに沿ったPython再現で確認 |
| 選別後の高い一致度が、独立参照での正しさを保証しない | 明示した最小モデルで反例を確認 |
| 一度取り込んだ信念は、以後どんな反証でも動かない | この一般化は不成立。tol以下の連続更新で移動できます |
| 再帰すれば必ず収束する | 受理規則だけでは不成立。周期的入力で往復できます |
| 反証拒絶が続けば、固定参照との乖離も必ず増える | 不成立。信念固定・参照固定なら一定です |
| coherence・panic・憲法検査など全部が改善する | 今回は未検証。これらを計算したことにはしていません |
| 実LLMの欺瞞や、自己改善の失敗を実証した | 未検証。有限の人工入力による状態分離と構造例です |

**今回支持できるのは、評価対象を選別した後の点数だけでは、実質的な改善を判断できない、という限定した主張です。** 出力、状態変化、独立参照との誤差、受理率を同時に記録する意味が確認できました。

## What “source replay” means

Exp A is not a native Julia execution. The repository’s `run_experiments.py` translates selected behavior from the pinned source and checks the source blobs before running. The caller supplies the apparent response in compliance arms. The pressure score describes social pressure and must not be confused with Exp C/D evidence strength.

Source file blob and SHA-256 values are stored in [`results/summary.json`](../results/summary.json). The source excerpts remain under their original [MIT license](../sources/hoho/LICENSE).

## What is synthetic

The B–F ordinary recursion, its internal coherence measure, input fixtures, independent reference, attractor criterion, injection schedule, and outcome classifier are experiment-harness definitions. The original `admits_section` implementation was not located in the inspected Hoho source. This repository therefore describes them as declared synthetic rules, never as native Hoho capabilities.

`CoreCommitment` and `constitutional_check` exist in the inspected broader project but are not scalar truth checks and are not modified or evaluated by A–F.

## Native status

Historical native Julia cross-check attempts did not complete successfully because of a runtime problem. The public snapshot keeps [`native_crosscheck.jl`](../native_crosscheck.jl) as an explicitly unvalidated comparison artifact. Native completion is not an A–F success condition and is not counted among the stored validation passes.

## Real AI boundary

No LLM was called, trained, fine-tuned, or introspected. No human-subject data were collected. A behavioral sequence audit of an LLM could be motivated by these results, but it would require independent observables and could not treat response differences as direct access to latent belief. That work has not been performed here.


## If the transition failed

Mark one or more:

```text
[ ] step was too large
[ ] wrong order
[ ] missing intermediate state
[ ] execution condition was wrong
[ ] reference criterion was unclear
[ ] current state was measured incorrectly
[ ] goal assumptions changed
```

Then define the repair:

```text
Revised path:
New intermediate state:
Reason for revision:
```
